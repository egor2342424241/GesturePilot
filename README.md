# GesturePilot

GesturePilot — приложение для Windows, которое позволяет управлять курсором и некоторыми действиями Windows движениями руки перед камерой. Видео обрабатывается локально: приложение не отправляет изображение с камеры на сервер.

> **Важно:** перед включением управления сначала проверьте жесты в предпросмотре. Если управление зависло, нажмите **«Аварийная остановка»** или уберите руку из кадра. У PyAutoGUI также оставлен аварийный failsafe: перемещение курсора в угол экрана может прервать управление.

## Установка и запуск из исходников

1. Скачайте ZIP-архив проекта и распакуйте его в обычную папку, например `C:\Apps\GesturePilot`. Не запускайте программу прямо внутри ZIP.
2. Установите **Python 3.11, 64-bit** для Windows. При установке желательно включить Python Launcher (`py`).
3. Убедитесь, что компьютер подключён к интернету: при первом запуске нужно скачать библиотеки.
4. Дважды нажмите `run.bat`. Скрипт создаст локальное окружение `.venv`, установит зависимости из `requirements.txt` и запустит приложение.
5. Если Windows спросит разрешение на доступ к камере, разрешите его для Python/GesturePilot.

Если `run.bat` сообщает, что не найден Python 3.11, переустановите 64-битный Python 3.11 с сайта python.org и включите Python Launcher. Если установка библиотек завершилась ошибкой, проверьте интернет и попробуйте запустить `run.bat` ещё раз.

## Первый запуск

1. Оставьте режим управления выключенным — вначале приложение показывает изображение с камеры.
2. В блоке камеры выберите правильный номер устройства. Если камера не открылась, попробуйте другой индекс.
3. Посмотрите на предпросмотр: ладонь должна уверенно попадать в кадр, освещение должно быть достаточным.
4. Для второй камеры включите режим двух камер, выберите другой индекс и укажите, какая камера управляет курсором. Это ручной выбор источника, а не калиброванное 3D-отслеживание.
5. Только после проверки изображения нажмите **«Включить управление»**.
6. Для немедленного отключения нажмите **«Аварийная остановка»**.

## Жесты мыши

| Жест | Действие |
|---|---|
| Большой + указательный пальцы соприкасаются | Левая кнопка мыши |
| Большой + средний пальцы соприкасаются | Правая кнопка мыши |
| Две руки одновременно делают щипок | Масштабирование/прокрутка в поддерживаемых сценариях приложения |
| Указательный и средний пальцы подняты, безымянный и мизинец согнуты | Режим колёсика |
| В режиме колёсика кисть движется снизу вверх | Колёсико вниз |
| В режиме колёсика кисть движется сверху вниз | Колёсико вверх |

Для колёсика удерживайте жест около 180 мс, затем двигайте кисть вверх или вниз. Пока распознаётся этот жест, курсор временно припаркован, а щипки не должны запускать клики. Если жест не определяется, попробуйте повернуть ладонь к камере и согнуть безымянный палец и мизинец заметнее.

## Назначение действий на жесты

Откройте вкладку **«Функции» → «Конструктор жестов»**.

1. Включите переключатель **«Разрешить жесты для окон Windows»**.
2. Напротив нужного жеста выберите действие.
3. Удерживайте жест перед камерой примерно полсекунды. После срабатывания действие не повторяется непрерывно: нужно отпустить/сменить жест и дождаться окончания короткой паузы.
4. Назначения и переключатель разрешения сохраняются между запусками.

Доступные действия:

- **Нет действия** — безопасное значение по умолчанию.
- **Показать рабочий стол (Win+D)** — показать рабочий стол; повторное нажатие обычно возвращает окна.
- **Свернуть все окна (Win+M)** — свернуть окна.
- **Обзор окон — выбрать вручную (Win+Tab)** — открыть системный обзор окон Windows. Нужное окно выбирается вручную; приложение не угадывает, какое окно вы хотите выбрать.
- **Переключить окно (Alt+Tab)** — перейти к следующему окну.
- **Закрепить окно слева/справа** — привязать активное окно к половине экрана.
- **Развернуть окно** — развернуть активное окно.
- **Свернуть активное окно (Win+Down)** — применить стандартную комбинацию Windows; её результат зависит от состояния окна.
- **Escape** — отправить Escape.
- **Диспетчер задач** — открыть диспетчер задач.

Назначения изначально выключены, чтобы жест случайно не свернул окна. Для действий с окнами используйте жест, который удобно удерживать и который вы не путаете с щипком или прокруткой. Жест V (два пальца) зарезервирован под колёсико, пока распознаётся специальная поза прокрутки; в этот момент назначенное действие для V не должно запускаться.

## Остальные настройки

- **Адаптивное сглаживание** — старается уменьшать дрожание, сохраняя скорость.
- **Сглаживание** — большее значение делает движение спокойнее, но может добавить задержку.
- **Защита от ложных кликов** — более строгая проверка жеста, чтобы уменьшить случайные нажатия; может потребовать более чёткого щипка.
- **Магнитный курсор** — мягко притягивает курсор к обнаруженным интерактивным элементам. Он не нажимает на них сам.
- **Радиус притягивания** — расстояние, с которого курсор начинает притягиваться к элементу.
- **Сила притягивания** — насколько сильно корректируется траектория курсора.
- **Подсветка цели** — показывает найденный элемент интерфейса. Поиск элементов Windows использует UI Automation; не все приложения предоставляют доступную информацию об элементах.

## Сборка EXE

В репозитории предусмотрен GitHub Actions workflow `.github/workflows/build-windows.yml`. После загрузки проекта в GitHub откройте вкладку **Actions**, запустите workflow **Build Windows EXE** через **Run workflow** или отправьте новый коммит. Сборка выполняется на Windows runner, после чего в результате workflow появится артефакт `GesturePilot-Windows-EXE`, который можно скачать.

Вручную на Windows можно собрать так:

```bat
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -r requirements.txt pyinstaller
.venv\Scripts\pyinstaller.exe --noconfirm --clean --windowed --name GesturePilot --icon assets\gesturepilot.ico --add-data "assets;assets" --collect-all mediapipe --collect-all cv2 --collect-all PySide6 main.py
```

Готовая папка будет в `dist\GesturePilot`. Сборку нужно проверять на Windows: наличие EXE само по себе ещё не подтверждает работу камеры на каждом компьютере.

## Приватность и ограничения

- Видео обрабатывается на этом компьютере; в коде нет отправки кадров на внешний сервер.
- Для распознавания используется MediaPipe; производительность зависит от камеры, освещения и компьютера.
- Вторая камера даёт дополнительный ракурс, но без специальной калибровки не измеряет точную глубину.
- Проверка в среде разработки включает статическую проверку Python и тесты упаковки. Реальную камеру, Windows UI Automation и готовый EXE нужно проверить на Windows-компьютере.

## Зависимости

Версии Python-библиотек закреплены в `requirements.txt`. При первом запуске `run.bat` установит их в `.venv`, чтобы не менять системный Python.
